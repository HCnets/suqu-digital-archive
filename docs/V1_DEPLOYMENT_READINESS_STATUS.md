## 7. 不允许放行的情况

出现任一情况，不能正式开放：

- `/api/health` 不是 MySQL 正式运行态。
- `npm run db:smoke:mysql:acceptance` 失败。
- 管理端无法登录或普通账号权限失控。
- 展示端无法读取已发布档案点位或专题内容。
- 上传文件无法打开，或上传目录暴露在 Web 静态根目录。
- 审核通过后公开接口读取不到已发布内容。
- 后台普通操作仍要求填写 JSON、内部编号或数据库字段。
- 未完成切换前备份。
- 未保存 V1.0 上线验收登记。
