# 阶段 9：可复制推广的红色文化 AI 数智化平台底座

更新时间：2026-07-15

## 1. 阶段目标

阶段 9 的目标不是继续堆叠静态内容，而是把当前“苏区镇数字档案”升级为可复制推广的红色文化 AI 数智化平台。

平台从广东省河源市紫金县苏区镇起步，底层必须支持未来扩展到省、市、县/区、镇/街道、村/社区、点位等多层级红色资源整合。

## 2. 质量红线

- 前台不再新增静态假数据。
- 后台功能必须有真实数据库、API、权限和审计日志。
- 发布内容必须经过审核。
- AI 生成内容只能作为草稿或辅助结果，不能直接公开发布。
- 真实老党员声音模拟必须以授权记录为前提。
- 数据库、上传文件、备份目录不得放在网站根目录。
- UI 必须达到可验收状态，不能以“功能能用但不好看”交付。
- 每个阶段必须本地验收通过后再进入下一阶段。

## 3. 总体模块

### 3.1 地区/项目配置中心

支持层级：

- 省
- 市
- 县/区
- 镇/街道
- 村/社区
- 点位

默认地区：

- 广东省
- 河源市
- 紫金县
- 苏区镇

能力：

- 一个后台管理多地区。
- 超级管理员全局管理。
- 普通账号按地区授权。
- 支持未来退化为单地区独立后台。
- 前台可按配置显示总览、当前地区、手动切换或定位推荐。

### 3.2 档案点位专门化

档案点位必须独立于通用内容表单，支持结构化字段：

- 标题、简介、正文
- 经度、纬度、年份
- 点位类型
- 所属区域/村镇
- 详细地址
- 历史时期
- 相关人物
- 相关事件
- 来源依据
- 图片/视频
- 讲解音频
- 风险等级
- 是否进入前台地图
- 是否进入内容列表
- 是否推荐首页
- 是否进入专题页
- 是否进入移动端导览

没有有效经纬度的内容不得进入地图点位。

### 3.3 发布位置控制

每条内容应支持独立发布位置：

- 地图
- 内容列表
- 首页推荐
- 专题页
- 移动端导览

后台可按内容类型配置默认发布位置。

### 3.4 点位详情新版

前台点位详情采用“博物馆展陈卡 + 沉浸式故事页”结合形态。

后台支持板块配置：

- 基本信息
- 历史背景
- 口述历史
- 图片/视频
- AI 讲解
- 时间线
- 相关人物
- 相关事件
- 学习问题
- 参观路线
- 群众留言
- 来源依据
- 风险提示/审校说明

后台应支持拖拽排序和 PC/移动/大屏预览。

### 3.5 口述历史模块

口述历史与档案点位同级重要。

字段包括：

- 受访人姓名
- 年龄/身份
- 采集地点
- 采集时间
- 采访人
- 音频
- 视频
- 转写文本
- AI 摘要
- 可公开版本
- 敏感片段标记
- 关联档案点位
- 审核状态
- 授权状态
- 授权文件

必须区分原始素材与公开版本。

### 3.6 AI 接入底座

超级管理员可管理：

- AI 供应商
- API Key
- 启用/禁用状态
- 测试连接
- 调用日志
- 模型能力类型：大模型、语音转写、TTS、数字人等

API Key 不得在后台明文回显。

### 3.7 AI 任务中心

支持自动和手动任务：

- 音视频转写
- 人物简介
- 事件时间线
- 地点关联
- 关键词
- 可公开摘要
- 风险提示
- 故事稿
- 讲解稿
- TTS 讲解音频

AI 结果必须进入审核。

### 3.8 审核增强

必须补齐：

- 驳回理由
- 退回指定节点
- 版本差异对比
- AI 内容标记
- 敏感风险标签
- 审核意见模板
- 审核记录导出

## 4. 第一里程碑

第一里程碑必须包含：

- 地区/项目配置中心
- 档案点位专门表单
- 前台点位详情新版
- 口述历史模块
- AI API 配置、任务框架、真实调用、手动导入
- API Key 超管管理
- PC/移动/大屏预览
- 前后端真实联动
- 审核安全闭环

## 5. 第一里程碑验收标准

- 后台可创建、编辑、停用地区。
- 后台可展示广东省/河源市/紫金县/苏区镇默认层级。
- 后台可给账号分配地区权限。
- 后台可创建结构化档案点位。
- 点位带有效经纬度后真实进入前台地图。
- 点位详情页由后台板块配置驱动。
- 后台可创建口述历史资料。
- 口述历史可关联点位。
- AI 供应商/API Key 可配置、可启停、可测试。
- AI 任务能真实调用或手动导入结果。
- AI 结果必须审核后才能前台展示。
- 前台 PC/移动/大屏不出现明显布局问题。
- 全部关键操作写入审计日志。

## 6. 开发顺序

1. 地区/项目配置中心数据模型与后台入口。
2. 账号地区权限。
3. 档案点位专门表单。
4. 前台地图读取结构化点位。
5. 点位详情板块配置。
6. 口述历史模块。
7. AI 配置与任务中心。
8. 审核增强。
9. 前台多设备体验升级。
10. 本地全链路验收。
